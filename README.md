# Chinook SQL Analysis

## Overview

This project is part of my ongoing journey to strengthen my SQL skills using MySQL.

I used the Chinook database to practice working with a relational database and answering business-style questions through SQL. Rather than following a step-by-step tutorial, I worked through the dataset independently and researched concepts when I got stuck.

I started with basic data exploration and data-quality checks, then progressed into JOINs, aggregations, and more advanced queries using subqueries.

## Questions Explored

- Checked important columns for NULL values
- Identified the top 10 customers by total spending
- Identified the top countries by customer spending
- Identified the top 10 artists by revenue
- Identified the top 10 genres by revenue
- Analyzed employee revenue performance
- Identified customers who spent more than the average customer
- Identified customers without purchases
- Identified artists generating above-average revenue
- Identified genres generating above-average revenue
- Identified tracks generating above-average revenue

## Database

The project uses the Chinook database, a sample relational database representing a digital music store.

The database contains tables related to:

- Customers
- Employees
- Artists
- Albums
- Tracks
- Genres
- Invoices
- Invoice Lines
- Playlists
- Media Types

## My Learning Approach

My goal with this project was not to simply copy solutions, but to understand how the tables relate to each other and how SQL can be used to answer questions from the data.

When I got stuck, I researched the relevant SQL concept and then attempted to apply it myself.

This project is an ongoing part of my SQL learning journey, and I plan to continue building on it with data visualization and Power BI.
